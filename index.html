Carnet de recettes

Vos recettes du web, disponibles même hors ligne.

8 caractères minimum.

Confidentialité : vos données restent sur cet appareil (IndexedDB). Le mot de passe est haché localement (PBKDF2) et n'est jamais transmis. Ce mode « local d'abord » protège l'accès sur un appareil partagé, mais n'équivaut pas à une authentification serveur.

Mon carnet

Pour les sites qui bloquent la lecture automatique. Il s'exécute dans votre navigateur, sur la page ouverte : aucun blocage possible, et il fonctionne aussi sur les sites en JavaScript.

Ordinateur : affichez la barre des favoris, puis glissez-y ce bouton.

🔖 Envoyer au carnet

iPhone / Android : mettez cette page en favori, puis modifiez-le et remplacez son adresse par le code copié ci-dessous. Sur une page de recette, ouvrez ce favori.
